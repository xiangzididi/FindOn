# 另一台电脑项目合并记录

来源：项目根目录 `Hackathon1st.zip` 与 `docs/对话记录新.txt`。

## 已采用

- 移动平台上的 E 轴采用双钩横梁，盒子具有对应双钩。
- 挂钩靠 E 轴伸入后 X 轴向右短移完成；脱钩靠回柜后 X 轴向左短移完成，不增加舵机。
- 左侧固定取物区、S01、S02 的机械布局。
- 产品结构概念图 `product-mechanism-concept-v1.png`。
- 开发顺序以实机最小闭环为先：安全点动 → 方向/比例 → 单格分步动作 → FETCH1/RETURN1 → 第二格 → 上位机。

## 最新实物确认与取舍

用户已确认 X 带 1:50 减速箱，X/E 均没有微动开关；这两项已合并到硬件配置、接线图和点动固件。

此前已明确两轴均为 1.8°、16 细分、2 mm 导程，所以 X 采用 80000 pulse/mm，E 采用 1600 pulse/mm。压缩包中的 8 细分/40000 pulse/mm 未采用，除非之后实机确认 PD42S1 已改为 8 细分。

压缩包固件允许无端点保护的连续高速 `SPIN X`，最高 160000 pulse/s，且没有软件时长上限；当前不采用。新的 `GEWU-AXIS-TEST-2.0-NO-ENDSTOPS` 仅允许每次解锁后的 0.1–1.0 mm 点动。
