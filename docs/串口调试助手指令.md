# PartGo 串口调试助手指令（5.2 mm）

## 1. 串口设置

- 串口：`COM9`
- 波特率：`115200`
- 数据位：`8`
- 停止位：`1`
- 校验位：`None`
- 流控：`None`
- 发送格式：文本（不要选 HEX）
- 行尾：`LF`，即 `\n`
- 若软件支持分包发送：每包最多 `64 bytes`，包间隔 `5 ms`

打开串口可能使 ESP32-S3 复位。每次重新打开串口后，都要重新确认机械原点。

> 当前固件没有限位开关和实体急停。发送任何运动指令前，必须确保区域无人无障碍。运动异常时立即发送单字符 `!`，不必等待换行。

## 2. 推荐方式：调用固件自动取还流程

### 2.1 心跳（必须开启）

在串口助手的“定时发送”中添加下面这一行，周期设为 `1000 ms`：

```text
{"v":1,"type":"status","host_session_id":"u"}
```

取出或归还运动期间，如果超过 `2000 ms` 没有收到同一 `host_session_id` 的心跳，控制器会停止并报告 `HOST_HEARTBEAT_TIMEOUT`。

### 2.2 查看状态

```text
STATUS
```

### 2.3 登记机械原点（本指令本身不运动）

仅当 X 位于最左侧取物零点、E 完全回缩、全部盒位已人工核对且区域清空时发送：

```text
{"v":1,"type":"command","task_id":"r1","cmd":"REFERENCE","config_version":6,"calibration_id":"sha256:cc1c95986974daccbf755497cff7d538567dadf5f3a38973d9f94a4cfc739ef8","host_session_id":"u","manual_reference_confirmed":true,"area_clear":true}
```

必须看到：

- `"phase":"REFERENCE_ACCEPTED"`
- `"phase":"HOME_CONFIRMED"`
- `"ok":true`

### 2.4 取出 S01

```text
{"v":1,"type":"command","task_id":"f1","cmd":"FETCH","slot_id":"S01","config_version":6,"calibration_id":"sha256:cc1c95986974daccbf755497cff7d538567dadf5f3a38973d9f94a4cfc739ef8","host_session_id":"u","area_clear":true}
```

必须等到 `task_id` 为 `f1` 的 `"ok":true`，并确认盒子已到左侧取物口，才能发送归还指令。

### 2.5 归还 S01

```text
{"v":1,"type":"command","task_id":"b1","cmd":"RETURN","slot_id":"S01","config_version":6,"calibration_id":"sha256:cc1c95986974daccbf755497cff7d538567dadf5f3a38973d9f94a4cfc739ef8","host_session_id":"u","area_clear":true}
```

### 2.6 取出 S02

```text
{"v":1,"type":"command","task_id":"f2","cmd":"FETCH","slot_id":"S02","config_version":6,"calibration_id":"sha256:cc1c95986974daccbf755497cff7d538567dadf5f3a38973d9f94a4cfc739ef8","host_session_id":"u","area_clear":true}
```

### 2.7 归还 S02

```text
{"v":1,"type":"command","task_id":"b2","cmd":"RETURN","slot_id":"S02","config_version":6,"calibration_id":"sha256:cc1c95986974daccbf755497cff7d538567dadf5f3a38973d9f94a4cfc739ef8","host_session_id":"u","area_clear":true}
```

每个 `task_id` 在同一次控制器会话中只能使用一次。重复测试时改为 `r2`、`f3`、`b3` 等新编号。

## 3. 不支持定时心跳时：短手动指令

每次运动都必须先单独授权，下面两行可以作为一组发送；随后必须等待 `STOP reason=PULSE_SEQUENCE_DONE_NOT_POSITION_FEEDBACK`，才能发送下一组：

```text
ARM X CLEAR
TRAVEL X 5.2
```

```text
ARM E CLEAR
PULSE E 100
```

规则：

- `TRAVEL X`：正数向右，负数向左；单次只能为 `1–20 mm`。
- `PULSE E`：正数伸出，负数回缩；单次只能为 `1–100` 个全步脉冲。
- E 轴对接总量为 `245` 脉冲，必须拆成 `100 + 100 + 45`。
- 勾取向右横移 `5.2 mm`，释放向左横移 `-5.2 mm`。
- 不要把多个运动组一次性粘贴。运动期间收到下一条普通指令，控制器会立即停止当前运动。

### S01 取出（从 X=0、E完全回缩开始）

依次执行并等待每一步 STOP：

1. X：`+20`、`+9.8`
2. E：`+100`、`+100`、`+45`
3. X：`+5.2`
4. E：`-100`、`-100`、`-45`
5. X：`-20`、`-15`

### S01 归还（盒子仍在取物机构上）

1. X：`+20`、`+15`
2. E：`+100`、`+100`、`+45`
3. X：`-5.2`
4. E：`-100`、`-100`、`-45`
5. X：`-20`、`-9.8`

### S02 取出（从 X=0、E完全回缩开始）

1. X：`+20`、`+20`、`+20`、`+20`、`+20`、`+5`
2. E：`+100`、`+100`、`+45`
3. X：`+5.2`
4. E：`-100`、`-100`、`-45`
5. X：`-20`、`-20`、`-20`、`-20`、`-20`、`-10.2`

### S02 归还（盒子仍在取物机构上）

1. X：`+20`、`+20`、`+20`、`+20`、`+20`、`+10.2`
2. E：`+100`、`+100`、`+45`
3. X：`-5.2`
4. E：`-100`、`-100`、`-45`
5. X：`-20`、`-20`、`-20`、`-20`、`-20`、`-5`

如果任何一步出现 `REJECT`、`TIMEOUT`、`HOST_HEARTBEAT_TIMEOUT`、异常声音、卡顿或丢步，不要继续后续位移累加；立即停止、切断 12V，并重新人工建立机械原点。
